# Contador de Tareas con useEffect y useMemo

Proyecto de contador de tareas desarrollado con React, useEffect y useMemo.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

### 1. Clonar el repositorio

cd proyecto3-contador-tareas

npm install

npm run dev

abrir en el navegador con http://localhost:3000
