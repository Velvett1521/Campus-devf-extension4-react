# Viaje del Explorador Espacial - Ciclo de Vida React

Proyecto para comprender el ciclo de vida de componentes con useEffect, useState y useMemo.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

### 1. Clonar el repositorio

cd proyecto4-explorador-espacial

npm install

npm run dev

abrir en el navegador con http://localhost:3000
