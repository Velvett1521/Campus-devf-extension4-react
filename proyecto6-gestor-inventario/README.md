# Gestor de Inventario - useReducer + useRef + useCallback

Proyecto de gestor de inventario para practicar hooks avanzados de React.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

### 1. Clonar el repositorio

cd proyecto6-gestor-inventario

npm install

npm run dev

abrir en el navegador con http://localhost:3000
