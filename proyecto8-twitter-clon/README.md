# Twitter Clon - Autenticacion y Proteccion de Rutas

Proyecto de clon de Twitter con sistema de autenticacion y proteccion de rutas en React.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

cd proyecto8-twitter-clon

npm install

npm run dev

abrir en el navegador con http://localhost:3000
