# Plataforma de Gestion de Citas Medicas - React Router DOM

Proyecto de plataforma para gestionar citas medicas utilizando React Router DOM.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

cd proyecto7-citas-medicas

npm install

npm run dev

abrir en el navegador con http://localhost:3000
