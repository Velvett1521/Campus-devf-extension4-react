# Tarjeta de Presentación con React + Vite

Proyecto de tarjeta de presentación desarrollado con React y Vite como parte del curso DEV.F.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm (viene con Node.js)

## Instalacion y Ejecucion

### 1. Clonar el repositorio

cd proyecto1-react-card

npm install

npm run dev

abrir en el nevagdor en http://localhost:3000
