# Lista de Compras Interactiva con React useState

Proyecto de lista de compras desarrollado con React y el hook useState.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

### 1. Clonar el repositorio

cd proyecto2-lista-compras

npm install

npm run dev

abrir en el navegador con http://localhost:3000
