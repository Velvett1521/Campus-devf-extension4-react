# Adivina el Numero - Conditional Rendering React

Proyecto de juego interactivo para practicar renderizado condicional y composicion de componentes en React.

## Requisitos Previos

- Node.js (version 18 o superior)
- npm

## Instalacion y Ejecucion

### 1. Clonar el repositorio

cd proyecto5-adivina-numero

npm install

npm run dev

abrir en el navegador con http://localhost:3000
